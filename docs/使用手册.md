# 求职工作台 · 使用手册

本地全栈应用，数据全部存本机，不上云、不联网。单端口 `7788`，前端由后端托管。

## 0. 启动与访问

```bash
cd /Users/hayson/Desktop/求职工作台
./scripts/start.sh
```

启动后浏览器打开 **http://localhost:7788**。

- **开机自启（可选）**：`./scripts/install_launchd.sh`，服务常驻后台，不用每次手动起。
- **手机访问**：服务绑 `0.0.0.0`，手机连同一 WiFi，浏览器访问 `http://<本机内网IP>:7788` 即可（数据不出内网）。
- **停止**：`launchctl unload ~/Library/LaunchAgents/com.jobseeker.workbench.plist`，或 `pkill -f "uvicorn server.main"`。

> 所有数据在 `data/`（`app.db` + `resumes/` + `backups/`），已加入 `.gitignore`，不会进仓库。

## 1. 首次使用建议顺序

1. **设置**：先填主方向（销售/运营/市场）、工作年限、学历、城市——影响匹配打分与方向统计。
2. **简历库**：上传你的简历文件（docx/pdf 自动解析文本），建多个版本并打方向标签。
3. **JD库**：粘贴 JD 原文 → 系统自动抽关键词/年限/学历，也可手动补。
4. **投递看板**：看到 JD → 选简历版本 → 新建投递 → 拖拽推进状态（意向→已投递→笔试→面试→Offer→关闭）。**每次投递必须绑定简历版本**，否则版本效果对比失真。
5. 后续用**面试中心、技能提升、人脉内推、面试题库**持续沉淀。

## 2. 各模块要点

- **驾驶舱**：漏斗转化率、三方向效果对比、简历版本效果、逾期跟进提醒，一屏掌握全局。
- **投递看板**：看板拖拽流转，状态机禁止跳阶段；非法拖拽会被拒绝并提示。
- **面试中心**：记录轮次/面试官/问题 → 复盘时填「答不出的题」，系统自动沉淀进**面试题库**并生成**技能差距项**进学习计划（闭环）。
- **AI工具**：见下一节。

## 3. AI 双通道（默认离线，零费用、零 key、数据不出本机）

1. 在 AI工具页点「导出 prompt」，复制生成的提示词。
2. 粘到任意 AI 对话（如本 WorkBuddy 对话）里跑，拿到结果 JSON。
3. 回工作台「导入结果」粘贴 JSON，系统做 schema 校验后入库；脏数据会被拒绝。
   - JD解析回填 → 更新 JD 结构化字段
   - 简历匹配回填 → 写入匹配分（并给出可一键加入技能计划的缺失项）
   - 面试题生成回填 → 入库到面试题库
4. **本地即时匹配**：不用 AI，点一下即得匹配分、缺失关键词与改写建议（规则引擎，纯本地）。
5. **在线模式（可选）**：设置页填 LLM key 并开启，应用内直连，结果同表存储。

## 4. 备份

- 驾驶舱/备份页点「导出备份」→ 生成全表 JSON + 投递/联系人 Excel，存到 `data/backups/`。
- 定期导出即可，整个 `data/` 目录也能直接拷贝打包。

## 5. 常见问题

- **页面打不开**：确认 `start.sh` 已运行、`7788` 端口未被占用。
- **改完代码后前端没变**：前端改动需重新 `cd web && npm run build` 生成 `server/static`。
- **想换云端**：所有数据读写走 `server/repositories` 抽象层，将来换 Postgres/REST 只需新增一个实现类，前端与业务代码不动；上云再加一个口令中间件即可。
